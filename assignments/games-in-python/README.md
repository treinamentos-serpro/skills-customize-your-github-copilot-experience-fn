
# 📘 Assignment: Jogo da Forca

## 🎯 Objetivos

Construa um jogo da Forca em Python para praticar manipulação de strings, loops, condicionais, entrada de dados e seleção aleatória.

## 📝 Tarefas

### 🛠️ Implementar o jogo da Forca

#### Descrição

Complete o arquivo `starter-code.py` para criar um jogo em que o jogador adivinha as letras de uma palavra secreta antes de esgotar o número de tentativas incorretas.

#### Requisitos

O programa concluído deve:

- Selecionar aleatoriamente uma palavra da lista predefinida.
- Inicializar e atualizar as letras já descobertas e os palpites incorretos.
- Aceitar palpites de letras e exibir o progresso atual, como `_ _ _ _ _ _`.
- Informar quando uma letra já foi escolhida e evitar que ela seja contada novamente.
- Encerrar quando a palavra for adivinhada ou quando o limite de tentativas incorretas for atingido.
- Exibir uma mensagem indicando vitória ou derrota.

Exemplo de progresso:

```text
Palavra: _ _ t _ _ n
Tentativas incorretas restantes: 4
Digite uma letra: p
```
